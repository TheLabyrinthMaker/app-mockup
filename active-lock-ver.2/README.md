# ActiveLock v2.0 - Fitness & Workout Tracker App Mockup

A comprehensive fitness tracking app mockup with customization features, achievements system, and workout tools.

## 🌟 Features

### 1. **Dashboard**
- Real-time activity statistics
- Calories burned, workout count, achievements, and goal progress
- Recent activity feed with workout history

### 2. **Achievements System** 🏆
Multiple achievement types to keep users motivated:

**Unlocked Achievements:**
- 🥇 **First Steps** - Complete your first workout
- 🔥 **On Fire!** - Complete 7 workouts in a week
- ⚡ **Speed Demon** - Run 5km under 25 minutes
- 💪 **Strong Start** - Complete 10 strength training sessions
- 🌅 **Early Bird** - Complete 5 morning workouts
- 📅 **Consistency King** - Workout for 30 consecutive days

**Locked Achievements (with progress tracking):**
- 🏃‍♂️ **Marathon Ready** - Run a total of 42km
- 🎯 **Perfect Month** - Complete all daily goals for a month
- 🌟 **Century Club** - Complete 100 total workouts
- 🏔️ **Mountain Climber** - Climb 1000m elevation total
- 🚴 **Cycling Champion** - Cycle 100km in total
- 🌙 **Night Owl** - Complete 10 evening workouts
- 🥋 **Flexibility Master** - Complete 20 stretching sessions
- 🏅 **Personal Best** - Beat your best time in any activity

### 3. **Profile & Customization** 🎨

**Profile Badges:**
- Display earned achievement badges on your profile
- 6 unlocked badges showcasing fitness milestones

**Theme Customization:**
Six fun color themes to personalize your experience:
- 🎨 **Default** - Classic green & blue gradient
- 🌊 **Ocean Blue** - Calming blue tones
- 🌅 **Sunset** - Warm orange & red gradient
- 🌲 **Forest Green** - Natural green shades
- 💜 **Purple Dream** - Vibrant purple theme
- ⚡ **Neon Nights** - Electric neon colors

**Profile Avatars:**
Choose from 8 different emoji avatars:
- 😊 Happy face
- 🏃 Runner
- 💪 Strong arm
- 🚴 Cyclist
- 🏊 Swimmer
- ⚡ Lightning bolt
- 🔥 Fire
- ⭐ Star

### 4. **Light & Dark Mode** 🌓
- Toggle between light and bright color scheme and dark mode
- Smooth transitions between themes
- Saves user preference in browser storage
- Accessible toggle button in top-right corner

### 5. **Customizable Rest Timers** ⏱️

**Quick Presets:**
- 30 seconds
- 45 seconds
- 1 minute (default)
- 1.5 minutes
- 2 minutes
- 3 minutes

**Custom Timer:**
- Set any duration up to 10 minutes
- Adjust minutes and seconds independently

**Timer Features:**
- Auto-start timer after each set
- Sound alert when timer completes
- Visual pulse animation during countdown
- Current session statistics (sets, minutes, calories)

### 6. **Walking & Running Routes** 🗺️

**6 Static Route Guides:**
Each route includes:
- Visual SVG path representation
- Start point (green) and end point (red) markers
- Distance in kilometers
- Estimated time
- Difficulty level (Flat, Easy, Mixed, Hilly)
- Star ratings with user count

**Route Types:**
- 🏃 **Running Routes** (3 routes)
  - Riverside Run (5.2 km, ~25 min, Flat)
  - Hill Challenge (7.5 km, ~40 min, Hilly)
  - City Circuit (6.3 km, ~30 min, Mixed)

- 🚶 **Walking Routes** (3 routes)
  - Park Loop (3.1 km, ~35 min, Easy)
  - Waterfront Walk (4.0 km, ~45 min, Flat)
  - Nature Trail (2.8 km, ~30 min, Easy)

**Filter Options:**
- View all routes
- Filter by walking routes only
- Filter by running routes only

## 🎯 Usage

1. Open `index.html` in a modern web browser
2. Navigate between tabs using the navigation menu
3. Toggle dark/light mode with the button in the top-right corner
4. Customize your profile in the Profile tab
5. Set up workout timers in the Workout tab
6. Explore routes in the Routes tab
7. Track achievements in the Achievements tab

## 💾 Data Persistence

The app uses browser localStorage to save:
- Theme preference (light/dark)
- Color theme selection
- Avatar choice
- Timer settings
- Auto-start and sound alert preferences

## 📱 Responsive Design

The app is fully responsive and works on:
- Desktop computers
- Tablets
- Mobile phones

## 🎨 Design Highlights

- **Modern UI** with smooth animations and transitions
- **Card-based layout** for easy scanning
- **Color-coded elements** for visual hierarchy
- **Accessible** contrast ratios in both light and dark modes
- **Visual feedback** for all interactions
- **Bright and appealing** color schemes

## 🚀 Technologies Used

- HTML5

- Vanilla JavaScript (no dependencies)
- SVG for route visualizations
- LocalStorage for data persistence
- Web Audio API for timer alerts
