# ActiveLock - Gamified Fitness App

A browser-based prototype of ActiveLock, a gamified fitness app designed to encourage physical activity by locking phones and rewarding genuine exercise.

## Features

### 🔒 Smart Phone Lock System
- Lock your phone during exercise sessions
- Timer tracks exercise duration
- Choose from multiple activity types (Running, Walking, Cycling, Gym, Yoga)
- Earn coins based on workout time

### 🔔 Notification Blocking
- Block notifications during exercise mode
- Pre-select allowed contacts who can reach you
- Emergency contacts always enabled
- Easy contact management

### 🎁 Rewards System
- Earn in-app currency (coins) for completed activities
- Unlock customizations and themes
- Track total coins earned
- Visual rewards showcase

### 🏆 Achievements
- Multiple achievement badges to unlock
- Track workout milestones
- Gamified progress system

### 👥 Leaderboard
- Global leaderboard rankings
- Compare with friends
- Weekly challenges
- Social motivation system

## How to Use

1. Open `index.html` in a web browser
2. Navigate between tabs: Lock, Rewards, Leaderboard, Settings
3. Start an exercise session from the Lock tab
4. Complete workouts to earn coins
5. Use coins to unlock customizations in the Rewards tab
6. Configure notification blocking in Settings
