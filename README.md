# OutdoorLife - Screen Time Reduction App Prototype

An HTML/CSS/JavaScript prototype of an app that reduces screen time and encourages outdoor activities.

## Features

### 🏠 Home Screen
- **Real-time Stats Display**: Shows screen time, outdoor time, and points earned
- **Daily Goal Progress**: Visual progress bars for outdoor activity and screen time goals
- **Milestones**: Track achievements and unlock badges

### 📊 Activity Tracker
- **Session Timer**: Start/stop outdoor activity sessions with live timer
- **Activity Types**: Select from walking, running, hiking, or cycling
- **Recent Activities**: View history of completed outdoor sessions
- **Point Accumulation**: Earn 1 point per minute of outdoor activity

### 🏆 Leaderboard
- **Friend Rankings**: Compare your progress with friends
- **Multiple Periods**: View weekly, monthly, or all-time rankings
- **Streak Tracking**: See who has the longest streak
- **Personal Highlight**: Your position is highlighted in the leaderboard

### 🎁 Rewards
- **Points Balance**: See your total available points
- **Badge Collection**: Unlock achievement badges as you progress
- **Redeemable Rewards**: Exchange points for real-world rewards (coffee, movies, dining, etc.)
- **Dynamic Availability**: Rewards automatically enable/disable based on your points

## Design Features

- **Bright Color Scheme**: Vibrant greens and blues to represent nature and outdoor activities
- **Clean Typography**: Modern, readable font stack for optimal user experience
- **Gamification Elements**: Progress bars, badges, milestones, and point system
- **Responsive Layout**: Optimized for mobile, tablet, and desktop presentation
- **Smooth Animations**: Fade-in effects and transitions for polished interactions

## How to Use

1. Open `index.html` in a web browser
2. Navigate between screens using the bottom navigation bar
3. On the Activity screen, select an activity type and click "Start Session" to begin tracking
4. Watch your stats update in real-time as you complete activities
5. Check the Leaderboard to see how you rank against friends
6. Visit the Rewards screen to unlock badges and redeem points

## Interactive Features

- **Screen Navigation**: Click bottom nav icons or use keyboard shortcuts (1-4)
- **Activity Tracking**: Start/stop sessions with visual timer feedback
- **Swipe Gestures**: Swipe left/right on mobile to navigate between screens
- **Reward Redemption**: Click reward buttons to spend points
- **Dynamic Updates**: Stats automatically update when activities are completed

## Technical Details

- **Pure HTML/CSS/JavaScript**: No frameworks or dependencies required
- **Responsive Design**: CSS Grid and Flexbox for flexible layouts
- **Modern CSS**: CSS Custom Properties (variables) for consistent theming
- **Vanilla JavaScript**: Clean, performant code without libraries
- **Accessible**: Semantic HTML and keyboard navigation support
